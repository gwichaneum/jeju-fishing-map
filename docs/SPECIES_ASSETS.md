## 식별상의 범위

- 한치: 제주 한치의 대표 대상인 창꼴뚜기 Uroteuthis edulis의 원명 Loligo edulis를 기재한 Hoyle(1886), Plate XXIII, Fig. 1을 사용했다. BHL/Internet Archive의 실제 도판과 설명을 대조했다. [주제주일본국총영사관의 지역명 설명](https://www.jeju.kr.emb-japan.go.jp/itpr_ko/11_000001_00289.html)을 대조했으며 지역명 한치의 모든 개체를 같은 종으로 단정하지 않는다.
- 무늬오징어: Berry(1914)의 원 표기 Sepioteuthis arctipinnis와 Commons의 Sepioteuthis lessoniana 동의어 표기를 함께 기록한다. 지느러미가 몸통 양옆에 넓게 이어지는 전신 도판이다.
- 부시리: Naturalis RMNH.ART.196의 일본산 Seriola aureovittata 도판이다. 원문 S. lalandi 동의어 표기와 분류 이력을 그대로 기록한다.
- 자바리: Hoshino, Senou & Nguyen(2024), Figure 1a의 **어린 Epinephelus bruneus**를 추출했다. E. moara 도판을 대용하지 않았다. 성체의 체색과 다르게 보일 수 있으므로 alt·변경 내역에 어린 개체임을 명시한다.
- 주꾸미: Totti의 Octopus ocellatus (= Amphioctopus fangsiao) 개체 사진이다. 팔을 자연스럽게 말고 있는 상태이며 참문어와 다른 원본이다. 팔 끝이 사진 경계에서 잘린 이전 후보는 채택하지 않았다.

## 정규화 재실행

브라우저 의존성은 추가하지 않았다. sharp는 Git 제외된 개발 도구 폴더에만 설치한다.

```powershell
npm.cmd install --prefix .verify --no-save --package-lock=false sharp
node scripts/normalize-species-assets.mjs --input .verify/species-sources --output assets/species --manifest docs/species-asset-processing.json
```

- 입력: .verify/species-sources/. 매니페스트 input 이름으로 downloadUrl의 실제 이미지 파일을 저장한다. .verify는 배포/Commit 대상이 아니다. 원본이 변경되거나 URL이 차단되면 재검토 후 진행한다.
- 출력: assets/species/<speciesId>.webp. 입력 원본을 덮어쓰지 않는다.
- mask는 원본 좌표(폭 1000 기준)에서 검토한 개체 외곽을 추출하기 위한 경계다. 이미지 속 생물 형태를 새로 만들지 않는다. 종이에 인쇄된 글자·눈금·주변 개체를 제외한다.
- 투명 이미지의 실제 불투명 영역을 기준으로 trim한 뒤 한 가지 비율로만 확대/축소한다. 512×512 canvas 중앙 정렬, 최대 길이 412px 및 원형 안전 반경 206px를 적용해 약 10% 여백을 확보한다.
- 마스크/색상 분리 결과는 전신·지느러미·촉수를 원본과 직접 대조해야 한다. 파일 존재나 자동 분리 성공만으로 품질을 판정하지 않는다.
- 재생성하면 species-catalog.json의 imageSha256도 갱신하고 검증기·브라우저를 다시 검사한다.

## 인수 상태

이미지 누락·needsAsset=true·중복 경로·동일 바이트·존재하지 않는 파일·원격 imageSrc·Placeholder는 모두 0건이다. 전체 31개 WebP를 브라우저에서 디코딩하고 투명도·원형 안전 여백을 확인했다. 목록·상세 src/filter와 CSS 컬러 전환 시 위치·크기 불변을 확인했다.

이미지 보완 당시에는 기존 7종의 정보 검토 경고로 엄격 인수가 보류되었다. 후속 [전체 정보 감사](./SPECIES_INFO_SOURCES.md)에서 해당 안내를 출처와 대조해 보완했으며 현재 일반·엄격 검증은 오류 0·경고 0이다. 이번 정보 작업에서는 31종 이미지 경로·실제 SHA-256 바이트가 모두 유지됨을 확인했다. 정보 출처 표는 별도 문서에서 관리한다.
