# 이미지 출처·사용 정책

이미지는 권한과 실제 대상의 형태를 모두 확인한 후 사용한다. 검색 결과 썸네일·공개 페이지 접근 가능 여부만으로 재배포 권한을 판단하지 않는다.
직접 촬영·제작한 자료도 권리자와 대상 정확성을 기록한다. 미확인 자료는 가짜 이미지로 보완하지 않는다.

## 저장과 증거

- 실제 파일은 기존 `assets/` 아래에 둔다. PNG/WebP/SVG 중 투명 배경을 우선한다.
- 외부 URL을 imageSrc로 쓰지 않는다. 다운로드 권한·라이선스가 확인된 파일만 로컬에 저장한다.
- 정보는 sourceUrl/license/attribution, 이미지는 imageSourceUrl/imageLicense/imageAttribution/imageVerified로 분리한다.
- 라이선스의 저작자 표기·변형 표시·동일조건·상업 이용 등 실제 의무를 확인하고 필요한 표기를 UI·문서에 반영한다.
- 권한 또는 종 정확성을 확인하지 못하면 imageSrc=null, imageVerified=false, needsVerification=true와 이유를 남긴다.
- SVG는 외부 리소스·script·추적 링크를 제거하고 검토한다. 파일 존재 검사만으로 이미지 안전성·권한·정확성이 증명되지 않는다.
- 서버 `staticFiles`에는 새 이미지의 필요한 경로만 등록한다. `.env`·프로젝트 루트 전체를 공개하지 않는다.

## 회색 잠금 표시

회색과 컬러 모두 같은 imageSrc를 사용한다. 잠금 전용 다른 이미지나 모든 종에 동일한 generic 물고기 실루엣을 쓰지 않는다.
CSS 상태만 전환해 크기·object-fit·회전·위치를 유지한다.

```css
/* 후속 Phase의 조정 예시. Phase 1에서 앱 CSS에 적용하지 않는다. */
.species-card[data-collected="false"] img {
  filter: grayscale(1) saturate(0) brightness(0.42) contrast(1.15);
  opacity: 0.75;
}
```

opacity 0.65~0.8을 시작점으로 원본·배경과 함께 확인한다. 너무 어두워 특징이 사라지면 조정한다.
갈치의 긴 몸, 광어의 납작한 체형, 돔류의 등지느러미, 학공치의 주둥이,
한치·무늬오징어·갑오징어의 몸통/지느러미 차이, 문어·주꾸미의 팔이 구별되어야 한다.
이 특징 목록 자체를 학명·종 판별의 검증 근거로 사용하지 않는다.

## 참고 화면의 사용 범위

Grid·둥근 frame·이름/상태·모바일 탐색 밀도만 참고한다. 참고 앱의 브랜드·입질확률·시간표·색상·아이콘과 어종 파일을 복사하지 않는다.
실제 참고 화면이 없으면 본 적이 있는 것으로 기록하지 않는다. 기존 제주 바다 배경·밝은 Glass Card·system font를 계승한다.

## 확인 방법

데이터 검증기로 로컬 경로·출처 필드·준비 상태를 검사한다. 직접 회색/컬러를 번갈아 보며 원본 동일성과 종별 형태를 확인한다.
어종별 고유 src를 검사해도 복제한 파일 내용·generic 도형 여부까지 자동 판정할 수 없으므로 시각 확인 결과를 별도 기록한다.
