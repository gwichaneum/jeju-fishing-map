# T01~T14 통합 인수 테스트

이 문서는 테스트 계획이며 실행 결과가 아니다. Phase 1에는 도감·기록·연동이 없어 해당 검사는 미실행이다.
변경된 실제 파일명이 아래 역할명과 다르면 실행 기록에 정확한 파일명을 남긴다.
개인 저장 데이터를 보존하기 위해 새 브라우저 profile 또는 별도 테스트 origin을 사용한다.

## 결과를 남기는 법

각 ID마다 PASS/FAIL/SKIP·일시·브라우저·viewport·절차·관찰값·증거 경로·실패 파일·수정/재검사를 기록한다.
기존 `npm test` 결과, 정적 검사, 실제 API 실연결, 브라우저 에뮬레이션, 실제 휴대폰/현장 검증을 구분한다.
원본 개인 데이터를 지우지 않고 사용한 테스트 기록만 정리한다. 스크린샷에 개인 사진·위치·키를 노출하지 않는다.
