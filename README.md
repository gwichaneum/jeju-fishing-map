# Jeju Fishing Map

## Run Locally

Run `node serve.cjs` from the project folder, then open http://127.0.0.1:8080.
No build step or API key is required. An internet connection is needed for the
MapLibre CDN and the OpenFreeMap Liberty style, vector tiles, and fonts.

If port 8080 is already in use, PowerShell can run `$env:PORT = "8081"; node serve.cjs`
and open http://127.0.0.1:8081 instead.

## 검색 및 필터

`spot-filters.js`에서 검색, 필터 옵션 생성, AND 조합, 결과 목록 및 초기화를 관리한다.
`script.js`는 기존 마커/팝업을 재사용해 표시 여부와 지도 이동을 처리한다.
별도 프레임워크나 검색 API, 데이터베이스는 사용하지 않는다.

- 검색 대상: 이름, 주소, 지역, 개인 메모, 공개 별칭, 공개/제보 어종, 낚시 방법.
- 부분 검색을 지원하며 공백으로 나눈 여러 단어는 모두 일치해야 한다. 영문 대소문자와 호환 문자는 정규화한다.
- 69개 전체 기록을 검색한다. 좌표 미확인 25곳은 목록에 `위치 확인 필요`로 남기고 선택을 막는다. 추정 좌표나 마커를 만들지 않는다.
- 지도 표시 개수는 조건에 맞는 좌표 확인 항목 수이며, 현재 화면 범위 밖의 마커도 포함한다. 전체는 44개이다.
- 검색 결과를 클릭/터치/Enter로 선택하면 기존 MapLibre `flyTo`로 해당 좌표로 이동하고 최소 zoom 13으로 확대한 뒤 동일한 팝업을 연다.
- 검색 결과 목록은 높이가 제한된 내부 스크롤 영역이다. 일반 문서 흐름에 배치해 필터, 지도 버튼, 마커를 덮지 않는다.
- 세 필터는 종류마다 하나씩 선택하며 검색어와 함께 AND로 적용한다. 선택하지 않은 `전체`는 조건에서 제외한다.
- 필터 변경 시 기존 마커를 제거/재연결한다. 선택된 포인트가 제외되면 팝업도 닫고, 기존 파란색/코럴 색상은 유지한다.
- `초기화`는 검색어, 세 필터, 결과 목록과 팝업을 지우고 44개 마커 및 현재 화면 크기에 맞는 제주 전체 보기를 복원한다.
- 키보드 Tab/방향키로 검색 결과를 이동하고 Enter로 선택할 수 있다. Escape는 결과 목록 또는 팝업을 닫는다.
- 지도 로딩 중에는 검색/필터를 비활성화하고, 지도 로딩 실패 시 오류 상태를 표시한다.

개인 메모의 어종/방법은 필터 판정에만 참고한다. `species`, `methods`, `reportedSpecies`,
`userNote`나 좌표를 변경하지 않으며, 기존 팝업의 공개/제보/메모 구분도 유지한다.
구체적인 어종만 인식하므로 `4대 돔`을 특정 어종으로 확장하지 않는다.
`서프루어`를 일반 `루어`, `넙치농어`를 `농어`, `무늬오징어`를 일반 `오징어`로 자동 분류하지 않는다.

### 현재 필터 목록

메뉴는 실제 배열/제보 어종과 개인 메모의 명시적 용어로 자동 생성한다. 가나다순이며 각 메뉴에 `전체`가 있다.

| 필터 | 현재 값 |
| --- | --- |
| 어종 (30개) | 갈치, 감성돔, 고등어, 광어, 넙치농어, 노래미, 농어, 다금바리, 독가시치, 돌돔, 무늬오징어, 방어, 벤자리, 벵에돔, 보리멸, 볼락, 부시리, 붕장어, 삼치, 숭어, 오징어, 우럭, 자리돔, 잿방어, 전갱이, 점다랑어, 참돔, 학꽁치, 한치, 혹돔 |
| 낚시 방법 (9개) | 구멍치기, 루어, 릴찌, 민장대, 서프루어, 에깅, 원투, 지깅, 찌낚시 |
| 포인트 유형 (3개) | 일반 낚시 포인트, 개인 저장 포인트, 접근 포인트 |

유형은 출처(`개인 즐겨찾기`)가 아니라 실제 `kind`를 따른다. `fishing-spot`은 일반,
`personal-spot`과 `landmark`는 개인 저장, `access-point`는 접근 포인트다.
따라서 개인 원본 목록에서 온 항구라도 `fishing-spot`이면 일반 유형에 속한다.
현재 표시 항목은 일반 39곳, 개인 저장 3곳, 접근 2곳이며 코럴 마커는 개인 저장/접근 5곳이다.

UI의 검색/초기화 아이콘은 Lucide 0.577.0의 정적 SVG로 프로젝트 내부에 저장했다.
런타임 아이콘 CDN은 추가하지 않았고 라이선스는 `assets/LUCIDE-LICENSE.txt`에 포함했다.

### 정보 구분

- `userNote`: 사용자가 제공한 메모 그대로. 어종이나 방법의 공개 검증 근거로 사용하지 않는다.
- `safetyNote`: 과거 개인 메모에서 분리한 안전 관련 표현. 현재 안전 보증이 아니다.
- `species`, `methods`: 해당 장소의 공개 낚시 자료에서 확인한 목록 또는 주요 항목.
- `reportedSpecies`: 이번에 사용자가 직접 제보한 추가 어종. 공개 자료의 어종과 분리하며 현재 조황이나 상시 출현을 보장하지 않는다.
- `source`: 개인 기록은 `개인 즐겨찾기`, 새 공개 기록은 `바다타임`.
- `externalSources`: 실제 참고한 공개 자료. 이름만 확인한 출처가 좌표 검증 출처가 되는 것은 아니다.
- `coordinateSource`, `coordinateScope`: 좌표의 근거와 범위.
- `kind`: 일반 낚시 장소와 개인 기준점/접근 지점의 구분.
- `locationNote`: 기준점과 실제 해안 낚시 위치가 다르다는 안내.
- `fishingInfoSource`: 어종과 방법의 근거. 관광지 좌표 출처와 별개로 관리한다.
- `additionalFishingInfoSources`: 추가 어종과 해당 어종을 소개하는 공개 출처. 기존 출처를 덮어쓰지 않는다.
- `verificationNote`: 확인 범위, 불확실성 또는 마커 제외 이유.

좌표는 공개 자료의 방파제/포구/해변 **대표 위치**이며, 사용자가 저장한 개인 핀의
정밀 위치를 복원한 것이 아니다. 출입 가능 여부, 낚시 허용, 현재 조황 및 안전을
보장하지 않는다. 공개 자료에 없는 어종과 방법은 빈 배열로 남겼다.
개인 메모만 있는 해수욕장, 용수포구, 용담포구, 북촌포구 등의 어종을 추정하지 않았다.
미확인 동귀방파제의 어종과 방법은 피싱맵에서 확인했지만 좌표가 없어 마커는 만들지 않는다.

## 근처 공중화장실

`restrooms.js`는 [제주특별자치도 제주시 공중화장실 공개 자료](https://www.data.go.kr/data/15110521/fileData.do)의
[공식 CSV](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003607188&fileDetailSn=1&insertDataPrcus=N)를
개발 중 한 번 내려받아 정리한 제주시 기록 141개와, 아래 POOPOO 공개 자료에서
이번 요청의 성산·남원 주변 후보를 확인한 보조 기록 6개로 구성된다.
앱 실행 중 크롤링/공공 API 요청은 없다.
요청한 [issuetale 참고 페이지](https://issuetale.kr/car/toilet/jeju/)는 403으로 접근할 수 없어
그 사이트의 자료를 수집했다고 표시하지 않았다.

주소가 `제주특별자치도`로 시작하고 제주 좌표 범위 안의 유효한 위도/경도를 가진
항목만 저장했다. 좌표/주소를 확인할 수 없는 기록은 제외했다.
폐쇄 보도가 있는 기존 현사마을 화장실 `PT0363`도 제외했다.
근거: [한라일보 현사포구 화장실 보도](https://www.ihalla.com/article.php?aid=1768097712780944044).
개방시간은 원자료를 유지하며 빈 값이나 `불규칙`은 `정보 없음`으로 처리했다.
`연중무휴`를 24시간 개방으로 바꾸지 않는다. 개방화장실에는 민간 개방 시설도 포함된다.

서귀포시 전체 자료를 확보한 것은 아니며 이번 요청 주변의 공개 후보 6개만 보완했다.
POOPOO는 공공데이터 참고 기록을 제공하는 보조 출처이며 이 6개를 제주시 공식 CSV
기록이라고 표시하지 않는다. 공개 자료의 주소/좌표/시간을 대조했지만 현장 검증은 아니다.
2024년 이후의 개방시간 변경 및 기관 시설의 외부인 이용 가능 여부는 직접 확인해야 한다.
새 좌표의 포인트를 추가하면 정적 데이터의 수집 범위도 다시 검토해야 한다.
좌표가 없는 포인트 25곳은 거리 계산에서 제외한다.

팝업 아래에 이름, 약 거리(직선거리), 시간, 주소, 관리기관, 기준일 및 출처를 표시한다.
수정된 현사포구에는 약 410m의 이호테우해변(상황실1층)(`상시`)이 연결된다.
일치하는 자료가 없으면 정확히 `500m 이내 확인된 공중화장실 정보 없음`을 표시한다.
이는 실제 화장실이 없다는 뜻이 아니다. 직선거리는 도보거리와 다르며,
원자료 이후의 폐쇄/시간 변경과 현재 이용 가능 여부는 현장에서 확인해야 한다.
화장실용 지도 마커나 토글은 추가하지 않았다.

`PT0356`과 같은 시설이므로 추가하지 않았다. 여러 포인트 검색에 반복된 성산일출봉
후보도 시설별 한 개만 저장했다. 현사어촌정주어항의 2023년 기록은 2025년 신축/폐쇄와
어느 시설인지 대조할 수 없어 제외했다. 폐쇄된 `PT0363`도 계속 제외한다.

## 공개 자료를 개인 항목에 연결한 명칭

### 제주항 부두 및 갈치 보완

서부두(ID 43)와 동부두(ID 45)는 삭제됐던 것이 아니라 어느 항구인지 미확인이라
마커를 보류한 항목이었다. 이번 사용자 요청으로 제주항임을 확인하여 기존 ID와
이름/메모를 유지하고 각각 육지 연결 서부두 방파제 끝과 동방파제 등대 기준점을 표시한다.
[OpenStreetMap 서부두 방파제](https://www.openstreetmap.org/way/452011513)의 끝점과
동방파제 등대를 개발 중 일회성으로 조회했고,
[과거 공식 검역구역 자료의 등대 좌표](https://www.law.go.kr/flDownload.do?bylClsCd=110201&flSeq=102421597&gubun=)와
대조했다. 이 과거 자료로 현재 출입 규정을 판단하지 않는다.
기존 제주항방파제 빨간등대(ID 52)는 바다 쪽 긴방파제의 별도 지점으로 좌표/어종을 바꾸지 않았다.

[피싱맵 제주항·서부두·동부두](https://fishingmap.co.kr/mobile/m_map_view.php?no=1020&wher=16)의
항만 주요 어종 목록으로 두 부두의 공개 어종을 보완했다. 부시리는 이 공개 목록에 포함된다.
갈치·점다랑어·잿방어는 사용자의 이번 제보를 `reportedSpecies`로 저장하며,
팝업의 `사용자 제보 어종`에 표시한다. 공개 자료와 중복되는 부시리는 한 번만 보여준다.
`모든 어종이 항상 잡힌다`고 표시하지 않으며 자료의 오래된 공사/진입 안내도 재사용하지 않는다.

애월항(ID 23)에는 [2025년 애월항 방파제 야간낚시 가이드](https://pigkim4.tistory.com/14)에서
대상어로 소개한 갈치를 추가하고 해당 출처를 별도 연결했다. 이는 공개 가이드의 대상어
안내이지 실제 현장 조사나 실시간 조황 검증은 아니다. 기존 바다타임 어종/방법과 출처는
유지한다. 갈치배 출항 안내나 먼바다 선상 조과만으로 다른 방파제의 어종을 추가하지 않았다.
나머지 66개 기록, 원래 메모, 화장실 147개, 지도 라이브러리/카메라/디자인은 그대로다.
동부두는 기존 500m 규칙에 따라 국제여객터미널 화장실(약 400m)과 연결되고,
서부두는 저장 자료 중 500m 이내 확인된 공중화장실 정보가 없다.

## Verification

Run `node --test tests/fishing-spots.test.cjs tests/restrooms.test.cjs tests/spot-filters.test.cjs`
for offline data, marker-eligibility, distance, search and filter tests.

브라우저에서 확인할 사항:

- 초기 제주도 전체 화면, 지도 이동/확대/축소, 출처 표시와 기존 바다 배경.
- 파란 마커 39개와 코럴 기준점 마커 5개. 가까운 항구는 확대해서 구분한다. 클러스터링은 아직 구현하지 않았다.
- 제주항 서부두/동부두와 기존 빨간등대가 각각 하나씩 있는지, 확대 후 클릭/터치로 구분되는지.
- 부두의 부시리와 사용자 제보 갈치/점다랑어/잿방어, 애월항 갈치의 별도 가이드 출처가 보이는지.
- 클릭/터치/Enter/Space로 팝업 열기, 다른 마커 선택 시 기존 팝업 닫기.
- 닫기 버튼/Escape로 닫기 및 키보드 포커스 복귀.
- 개인 메모와 공개 어종/방법이 분리되어 있는지, 빈 항목이 숨겨지는지.
- 안전 메모가 현재 안전 보증으로 보이지 않는지.
- 좁은 모바일 화면에서 팝업 내부 스크롤과 닫기 버튼, 가로/세로 전환.
- 개인 기준점 배지와 위치 참고 문구, 미확인 장소의 마커가 없는지.
- 화장실 영역까지 스크롤할 수 있는지, 수정된 현사포구의 이호테우해변 연결과 성산/신산/남원 시설의 시간·출처·기준일이 보이는지.
- 현사포구가 하나만 남았는지, 제공한 주소의 기준점과 실제 해안 발판의 차이 및 태흥리 1214-6의 정확한 위치.
- 정보가 없는 포인트에서 `화장실 없음`으로 단정하지 않는지, 실제 해안 접근/시설 개방 여부.
- `현사포구`, `성산`, `애월`, `태흥`, `무늬`, `벵에`와 주소/메모로 검색하고 결과의 지도 이동, 팝업/화장실 내용을 확인한다.
- `태흥1리`처럼 위치 미확인 결과는 선택할 수 없으며 마커도 없는지 확인한다.
- 검색 `성산` + 어종 `무늬오징어` + 유형 `접근 포인트`는 주차장 1곳, `태흥` + `무늬오징어` + `에깅` + 일반 유형은 덕돌포구 1곳인지 확인한다.
- 개인 저장 + 무늬오징어 + 에깅처럼 모두 만족하는 기록이 없으면 0개/빈 결과를 표시하고 어종/방법을 추정하지 않는지 확인한다.
- 긴 필터 값, 결과 목록 스크롤, 한글 입력 조합, 키보드 focus/Enter/Escape, 초기화 후 제주 전체 보기와 44개 마커를 확인한다.
